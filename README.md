# EventBiz — Garba pass selling demo

**Admin** · **Customer** · **Scanner**

Flow: Admin lists inventory → Customer buys QR passes → Scanner verifies entry.

## Run

```bash
npm install
npm run dev
```

- App: http://localhost:5173  
- API: http://localhost:3001
